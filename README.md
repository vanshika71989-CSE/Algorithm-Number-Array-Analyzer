# Algorithm-Based Number & Array Analysis System Using Python

## Overview

This project is a Python-based system that performs different number, array, mathematical, and conversion operations using basic algorithms. The project is designed to apply programming concepts such as functions, loops, conditional statements, arrays, and algorithmic problem solving.
## Features

- Number Analysis
  - Prime Number Check
  - GCD
  - Prime Factorization
  - Smallest Divisor
  - Palindrome Check
  - Fibonacci Series

- Array Analysis
  - Maximum Element
  - Array Reversal
  - Counting Elements
  - Remove Duplicates
  - Kth Smallest Element

- Mathematical & Conversion Operations
  - Factorial
  - Power
  - Square Root
  - Base Conversion
## Technologies Used

- Python
- Jupyter Notebook
- Basic Algorithms
- Lists and Functions
- Git and GitHub
## Project Structure

- `main.py` - Main menu and program control
- `number_analysis.py` - Number analysis operations
- `array_analysis.py` - Array analysis operations
- `mathematical_operations.py` - Mathematical and conversion operations
- `input_validation.py` - Input validation functions
- `test_cases.py` - Test cases for the implemented functions
- `Algorithm_Number_Analyzer.ipynb` - Project development notebook
## How to Run

1. Make sure Python is installed on the system.
2. Keep all project files in the same folder.
3. Open the project folder in Jupyter or a Python environment.
4. Run `main.py`.
5. Select the required option from the main menu.
## Testing

The project includes test cases for important number, array, mathematical, and conversion operations. The test cases are used to verify that the implemented functions produce the expected results for different inputs.
